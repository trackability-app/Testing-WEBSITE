Pre-launch marketing website for Trackability.

- `index.html` — complete landing page

## Current workspace

https://trackability-app.github.io/Trackability/

## Theme

The site includes a persistent light/dark mode toggle. The selected theme is saved in the browser with `localStorage`.

## Future expansion

More screenshots and explanatory "How to use Trackability" sections can be added later without changing the overall structure.

## Notes

- No videos are used.
- Real product screenshots are used throughout.
- Product-tour tabs switch screenshots with vanilla JavaScript.
- Scroll-reveal animations are implemented with vanilla JavaScript.
- When the mobile app launches, the main CTA can be changed to the Google Play / App Store URL.
