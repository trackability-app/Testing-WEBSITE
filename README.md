# Trackability Website Package

A creative marketing/product website for Trackability, prepared from the uploaded Trackability app HTML.

## Included
- `index.html` — main marketing website
- `styles.css` — animations and responsive styling
- `screens/` — app feature preview artwork derived from the supplied app UI structure
- `app-demo/index.html` — the supplied app HTML, included as a demo copy
- `docs/privacy.html` — privacy policy draft
- `docs/terms.html` — terms and conditions draft

## GitHub Pages
Upload the contents of this folder to the repository you want to use for the Trackability website. The main page is `index.html`.

## Social links
Instagram/Facebook/X links are currently generic platform destinations. Replace them with the official Trackability profile URLs when those accounts are created.

## Important
The `screens/` visuals are feature-preview recreations based on the supplied app source; they are not raw device captures. This keeps the website self-contained and avoids depending on external screenshot hosting.
