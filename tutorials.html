How to use it

Tutorials, with the real interface.

Step-by-step guides using the actual Trackability screens — no invented mockups.

01 / Planning

Add and manage a time block

  1. Open the Tasks & Schedule area.
  2. Choose the date and add your task.
  3. Give it a start/end time or duration.
  4. Attach subject/chapter context when useful.
  5. Use repeat/reminder options when the work recurs.
02 / Focus

Start a focused study session

  1. Choose Study, Revision or Other.
  2. Select subject/chapter if required.
  3. Choose 25, 50, 90 minutes or a custom duration.
  4. Start, pause/resume and finish the session.
  5. Use Pomodoro when you want work/break cycles.
03 / Study

Build your syllabus and revision flow

  1. Open Syllabus and select the subject.
  2. Review chapter completion.
  3. Mark chapters/topics that need revision.
  4. Open Revision Hub to collect those topics.
  5. Add the revision item to Tasks when you're ready to schedule it.
04 / Tests

Log a Grand Test

  1. Open Grand Tests.
  2. Enter test name and platform.
  3. Record total questions, correct, wrong and left.
  4. Let the configured marking scheme calculate the score.
  5. Use the history/trend view to compare tests.
